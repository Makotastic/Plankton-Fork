# 2.5-D Mapping Plan for RexROV

## Goal
Build a **2.5-D elevation map** of the seafloor and pipeline using RexROV’s forward multibeam sonar. This adds vertical detail (z-values) to the map, improving robustness for multi-robot alignment and navigation.

## Inputs
- **Sonar**: `/rexrov/points` (PointCloud2) or `/rexrov/depth/image_raw`
- **Pose estimate**: `/rexrov/odom` (simulation ground truth now; later EKF with IMU + DVL + pressure)
- **Transforms**: `map → odom → base_link → sonar_frame`

## Outputs
- **Elevation map**: `/elevation_map` (2.5-D grid storing mean height + variance per cell)
- **Occupancy grid (derived)**: `/map` (`nav_msgs/OccupancyGrid`) for frontier detection and Nav2
- **Submaps/tiles**: fixed-size elevation tiles with local pose for map-server exchange

## Steps
1. **Parse sonar data** → convert depth/points into XYZ in sonar frame.
2. **Transform points** into global `map` or `odom` frame using TF.
3. **Grid integration**:
   - Resolution: 0.1–0.25 m cells
   - Per-cell running mean + variance of height
   - Outlier rejection with variance gating and min hit count
4. **Submapping**:
   - Accumulate tiles (e.g. 50×50 m) with pose stamped
   - Save/send tiles for swarm map-server
5. **Optional raycasting**:
   - Mark free cells along beams
   - Output a 2-D occupancy grid `/map` alongside elevation data
6. **Visualization**:
   - RViz: publish elevation grid as an image layer or PointCloud2 for debugging

## Timeline
- Week 1: Wire TF, parse sonar, basic elevation integrator
- Week 2: Add tiling, occupancy projection, logging, parameter tuning
- Later: Upgrade to EKF odometry, add inter-robot submap alignment

## Benefits
- Robust submap alignment (SE(3) instead of just SE(2))
- Clearer pipeline geometry for inspection
- Easy fallback to 2-D occupancy for frontier exploration
